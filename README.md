# ريموتك — قاعدة توافق الريموتات

تطبيق ويب عربي RTL للبحث عن توافق ريموتات أجهزة الاستقبال والتلفاز وإدارة الأجهزة والريموتات من لوحة مشرف. مبني باستخدام PHP 7.4 وMySQL وPDO دون مكتبات خارجية.

## المزايا
- بحث واقتراحات فورية حسب شركة الجهاز أو موديله.
- عرض الريموتات المتوافقة ونوع التوافق وملاحظاته.
- لوحة إدارة محمية بتسجيل دخول المشرف.
- إنشاء وتعديل وحذف الأجهزة والريموتات وربط عدة ريموتات بالجهاز.
- حماية نماذج الإدارة برمز CSRF، وتخزين كلمات المرور باستخدام `password_hash`.
- يعمل على PHP 7.4+ وMySQL 5.7+.

## المتطلبات
- PHP 7.4 أو أحدث مع إضافتي `pdo` و`pdo_mysql`.
- MySQL 5.7 أو أحدث.
- Apache أو Nginx، أو خادم PHP المدمج للتجربة.

## التثبيت لأول مرة
1. نزّل المشروع وفك ضغطه، ثم أنشئ قاعدة البيانات باستيراد `database/schema.sql`:

```bash
mysql -u root -p < database/schema.sql
```

إذا كان اسم مستخدم MySQL أو كلمة مروره غير افتراضيين، اضبطها في `config/database.php` أو متغيرات البيئة `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASS`.

2. أنشئ حساب المشرف من سطر الأوامر. كلمة المرور يجب ألا تقل عن 12 حرفًا:

```bash
php scripts/create_admin.php admin 'ضع-كلمة-مرور-قوية-هنا'
```

لا تضع كلمة المرور الحقيقية في سجل الأوامر المشترك أو مستودع عام. على خادم حي استخدم كلمة مرور فريدة وقوية.

3. وجّه جذر الموقع (document root) إلى مجلد `public`، أو للتجربة شغّل:

```bash
php -S 127.0.0.1:8000 -t public
```

4. افتح `http://127.0.0.1:8000/` للبحث، و`http://127.0.0.1:8000/login.php` لدخول المشرف.

## تحديث قاعدة موجودة
إذا سبق إنشاء الجداول وتريد إضافة تسجيل دخول المشرف دون حذف البيانات، نفّذ فقط:

```bash
mysql -u root -p remotes_db < database/admin_migration.sql
```

**تنبيه:** `database/schema.sql` مخصص للتثبيت الجديد، ويعيد إنشاء جداول الأجهزة والريموتات؛ لا تعِد استيراده على قاعدة بيانات تحتوي بيانات تريد الاحتفاظ بها.

## تنزيل نسخة ZIP
من صفحة المستودع اضغط **Code → Download ZIP**. لتنزيل ملفات فرع `main` مباشرة من المتصفح، استخدم زر التنزيل في GitHub أو الرابط:

`https://github.com/slimon82/remotes/archive/refs/heads/main.zip`

## الأمان والنشر
- لا تجعل `config/` أو `src/` متاحين مباشرة للويب؛ اضبط جذر الموقع على `public/`.
- استخدم HTTPS في الاستضافة، واحتفظ ببيانات الاتصال خارج المستودع في متغيرات بيئة للخادم.
- احذف بيانات التجربة قبل النشر إن لم تكن مطلوبة.
- التطبيق لا ينشئ حساب مشرف افتراضيًا؛ يجب إنشاؤه يدويًا بأمر CLI.
